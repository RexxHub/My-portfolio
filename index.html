01 / The product

Made for the realities of exam day.

REXVA is a Windows-based computer-based testing system. Set up the host computer, connect the school lab, and manage the exam from one place.

01 / Keep the exam moving

Run the exam on your school network.

Install REXVA on a Windows host computer and connect student lab PCs over the local wired or wireless network. Exams can run without internet access.

  • One attempt per student
  • Timed schedules and pass marks
  • Shuffled questions and options
02 / Set clear conditions

Give every student the same structure.

Configure timing, question order, and exam access. Fullscreen mode, integrity logs, and automatic submission help keep each session organized.

  • Multiple choice, true/false, short answer
  • Question images and spreadsheet imports
  • Server-controlled exam schedules
03 / Protect the last mile

Save answers. Recover work. See results.

Saved answers, recovery after interruptions, and automatic backups support continuity. REXVA scores exams, prints results, and exports data as CSV.

  • Instant scoring and printable results
  • CSV export for school records
  • Optional sync to the teacher dashboard
